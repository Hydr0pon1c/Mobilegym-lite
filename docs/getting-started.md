# Getting started

The [root README](../README.md#start-the-simulator) contains the installation,
companion dataset, and simulator commands. [`.env.example`](../.env.example)
describes optional simulator keys; the shipped task snapshots are the starting
point for benchmark runs.

For individual state-judged tasks, see [the benchmark guide](../bench_env/README.md).
For accelerator training and checkpoint evaluation, use [the training guide](../mobilegym-rl/README.md).
