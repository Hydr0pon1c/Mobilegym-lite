# Tools

- `server/start_nginx_gateway.sh`: serve a production build and the Python API gateway.
- `server/api_gateway.py`: local network proxy and runtime endpoints.
- `check_release.py`: check the release inventory, portable configuration, and artifact boundary.
- `build_nav_artifacts.mjs`: generate navigation artifacts after changing declarations.
- `check_navigation_declaration_consistency.mjs`: validate routes and action declarations.
- `lint_store_getters.mjs`: check state getter conventions.
- `bench/audit/`: task-index and recorded-trajectory resource inspection.
- `ime/build_pinyin_dict.mjs`: build the input-method dictionary.

Run the simulator, training, and evaluation commands from the [root README](../README.md).
